# AutoCare Inventory Mini

This repository contains the scaffolding for the AutoCare Inventory Mini application.

## Structure

- `client/` React frontend
- `server/` Node.js + Express backend
- `design/` design assets and screenshots
- `docs/` project documentation

## Getting Started

1. Install frontend dependencies in `client/`
2. Install backend dependencies in `server/`
3. Configure environment files from `.env.example`
4. Run the client and server separately
